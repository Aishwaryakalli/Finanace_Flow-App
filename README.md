# Finance Flow App

## What is Flow?
Flow is a personal finance web application 
designed to make money management simple 
and stress-free for everyone.

## Why Flow?
Most finance apps are too complex and 
confusing. Flow makes it easy — anyone 
can understand their finances in seconds 
without any financial knowledge.

## How It Helps You
- See your complete financial health 
  in one single wellness score
- Understand spending instantly 
  with visual charts
- Track savings goals easily
- Get smart personalized tips
- Clean dark theme — easy on eyes
- Works on any device — mobile friendly
- Takes less than 2 minutes to learn

## Features
- Financial Wellness Score
- Spending tracking by category
- Savings goals tracker
- Multi-user profiles
- Mood check-in feature
- Dashboard with income & expenses

## Technologies Used
- HTML5
- CSS3
- Vanilla JavaScript
